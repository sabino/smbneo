Browser player

Play the Neo Geo port online

Choose your own supported .nes file, a ZIP containing it, or a locally built smbneogeo.zip. The file is processed entirely inside your browser and is never uploaded.

Ready when you are

Select your local game image to prepare the Neo Geo cartridge.

Waiting for a local file.

When the player appears, select Play SMBNeo, then press 1 at the title screen. Click the game if keyboard focus moves away.

Bring your own game

This site contains the open-source port and an open Neo Geo BIOS, but no original game ROM or generated cartridge. Graphics are created in memory from the file you select and disappear when the page is closed.
